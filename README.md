# Project Manager

Sistema en desarrollo para gestionar avances, entregables y comentarios entre diseñadores y clientes, basado en necesidades observadas durante el trabajo en Geme.

## Estado

**En desarrollo.** La arquitectura y las funcionalidades todavía están evolucionando, por lo que este repositorio no se presenta como un producto finalizado.

## Problema que busca resolver

Centralizar el seguimiento de proyectos creativos en un único flujo: avances, archivos, revisiones y comentarios del cliente, evitando que el estado de cada trabajo quede repartido entre mensajes, documentos y conversaciones separadas.

## Alcance previsto

- Registro y seguimiento de proyectos.
- Estados de avance y entregables.
- Comentarios y observaciones asociados a cada proyecto.
- Separación entre vista de trabajo interno y revisión del cliente.
- Historial básico de cambios y seguimiento de pendientes.

## Objetivo técnico

Construir una herramienta interna que permita practicar y demostrar desarrollo backend, modelado de datos, integraciones y automatización de flujos de trabajo sin mezclar este proyecto con otras utilidades operativas.
